# マルバツクイズ｜職場のハラスメント

職場のハラスメント（セクハラ・パワハラ・マタハラ・カスハラなど）の線引きを○×で10問出題し、1問ごとに解説を表示して100点満点で採点するブラウザクイズです。スマホのホーム画面に追加するとアプリのように使えます（PWA）。

公開URL: https://masatopapa.github.io/harassment-marubatsu/

- 解説はAIが作成したものです。法令の施行時期などは変わることがあるので、最新の情報を確認してください。
- 更新はネット優先のService Workerで自動配信されます（次に開いたときに新版になります）。
